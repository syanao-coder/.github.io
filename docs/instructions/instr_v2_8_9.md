# v2.8.9 指示書 ─ 音量ミキサーとマスター音量の独立

発行: 2026-10-02（Claude Code。管理と開発を同じセッションで行う）
基点: `index.html` v2.8.8 / アドオン 2.8.7 / `debug_suite.js` v1.10.0
読む仕様書: `get-dev-workflow` / `get-debug-suite` / `get-ui-spec`（1節・9節）/ `get-protocol-spec`（0-1節・11節 R-5 / R-6）
種別: **パッチ（A側のみ・プロトコル変更なし・アドオン無変更 → `ADDON_REQUIRED_VERSION` は 2.8.7 のまま）**

## 1. やること

| # | 内容 |
| :-: | :--- |
| R-5 | 上部メニューに **🔊 音量**（6枚目のトップメニュー）。マスター音量と、枠ごとの音量スライダーを **枠の並び順に「枠N＋種類＋タイトル」付き**で並べる。**行にマウスを乗せると対象の枠が光る**（どのスライダーがどの枠か分かるように） |
| R-6 | **実際の音量 ＝ マスター × 枠ごと。** マスターを動かしても枠ごとの音量に触らない。下部の音量とミキサーのマスターは同じ値を共有する |

## 2. 着手前に実コードで確かめたこと

| # | 確認 | 結果 |
| :-: | :--- | :--- |
| 1 | `changeMasterVolume()` | 全ローカル動画の `video.volume` と操作バーの `localVolume_*` 欄、全 YouTube の `setVolume()` を**マスターの値で上書き**していた ＝ 利用者の言う「個別に合わせた差がリセットされる」の原因 |
| 2 | YouTube の `onReady`（新規・セッション復元の2経路） | `setVolume(masterVolume)`。2経路とも実効音量へ変える |
| 3 | ローカル動画の操作バーの音量欄 | `video.volume` を直接書いていた。**この欄は「枠ごとの音量」を表すように変える**（ミキサーと同じ値） |
| 4 | dアニメ・Amazon | A→B のメッセージに音量が無い（`get-protocol-spec` 3節）。**対象外**（入れるならマイナー） |
| 5 | トップメニューの排他 | `TOP_MENUS` への登録だけで済む（`get-ui-spec` 1節）。`debug_suite.js` の `MENUS` も6枚にする → **`D-M2` は 30遷移 → 42遷移（判定 34 → 46）** |

## 3. 保存

| キー | 中身 |
| :--- | :--- |
| `sync_master_volume` | マスター（既存のまま） |
| `sync_card_volume`（新） | `{ cardId: 0..100 }`。既定 100。**消えた枠の値は保存のたびに捨てる** |

## 4. 判定（`debug_suite.js` v1.11.0）

| ID | 内容 | PC |
| :--- | :--- | :--- |
| `D-A1` | 🔊 を押せて開く・行の数と並びが枠と一致・「枠N」の番号・行ホバーで枠が光り外すと消える・ミキサーのマスター＝下部・閉じたら光が残らない | ボタンとパネルがある・枠が1つ以上 |
| `D-A2` | 🔴 枠A 80 / 枠B 30 にしてマスターを動かしても 80 / 30 のまま・実効音量＝マスター×枠ごと・保存される・操作バーの音量欄が枠ごとの値 | 🔴 マスターを変えると実効音量が変わる（**独立性に依存させない** ─ 依存させると壊れたとき「判定不能」になり不合格として出ない） |

- 2本とも準備不要なので **「▶ すべて実行」に入れる（21本 → 23本）**。`D-M2` の判定数が 34 → 46 に変わる（6枚目のメニュー）。
- `D-N3` 31 → 32、`EXPECT_APP_VERSION` 2.8.9、`EXPECT_ADDON_REQUIRED` は 2.8.7 のまま。
- 申し送りだった設置ガードの文言を「URL は変えずに Ctrl+Shift+R」へ直した。
- headless Chromium で、旧挙動（マスターが枠ごとの値を上書き）を注入すると `D-A2` が **不合格（1/6）** になることを確認済み。
