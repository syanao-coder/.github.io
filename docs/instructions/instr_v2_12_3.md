# v2.12.3 指示書 ─ v2.12.2 でライブのチャットが流れなくなった不具合の修正

発行: 2026-10-24（Claude Code）
基点: `index.html` v2.12.2 / アドオン 2.12.0 / `debug_suite.js` v1.22.0
読む仕様書: `get-dev-workflow` / `get-debug-suite` / `get-chat-feature-spec`（1-6-3節 コメントの時刻 `t`）/ 指示書 `instr_v2_12_2.md` / 記録 `report_v2_12_2.md`
種別: **パッチ（A側だけ・プロトコル変更なし）。アドオンは 2.12.0 のまま**

## 1. 不具合（v2.12.2 実機 2026-10-24）

ページを開いた時点より後のライブのコメントが、チャット欄にも流しにも一切出ない。`D-W4` の後半: 届いたチャンク 2回（3・34件）・表示 0件・K 0ms。

## 2. 原因（実コード）

- コメントの時刻 `t` は **配信開始からの経過 ms**（`chat_fetcher_main.js`: `timestampUsec / 1000 − liveStartMs`）。
- `liveSmoothIngest` の `now` は **`performance.now()`＝ページを開いてからの経過 ms**。
- `now − t` には「ページを開いた時刻 − 配信開始時刻」の符号を反転した定数が乗る。配信開始の後にページを開くと**大きな負**。v2.12.2 はこれを遅れとみなし、`K = max(…, 0)` で 0 に丸めた → `due = t + 0` ＝ 数時間先 → 出ない。
- 🔴 `D-A5` と headless の検証台は `t` を `performance.now()` 基準で作っていたので、この取り違えを再現しなかった（管理側の誤り・`report_v2_12_2.md` 5節）。

## 3. 修正

- `store.liveLagBase` ＝ これまでの `now − t` の**最小**（＝最も新しいコメント。起点の差＋最小の遅れ）。遅れは `now − t − base`（相対）。
- 出す時刻 `due = t + base + K`。`MAX_LAG`（30秒）との比較も相対の遅れで行う。
- 🔴 保険: どう計算が狂っても `due ≤ now + 30秒`。
- 版数: `APP_VERSION` 2.12.3・`APP_HISTORY` 45件・`debug_suite.js` v1.22.1（`D-N3` 45）。
