## 3. 設計

### 3-1. 音の通り道（枠の中・アドオン 2.16.0）

```
video → src ─┬─ bypass（Gain 1）────────────────────────┐
             ├─ LP → LP（低い側・帯域の境）──┐            ├─ mix → destination
             └─ HP → HP（高い側）→ Compressor ┴─ wet（Gain 0）┘    └→ Analyser（メーター）
```

- 境は Linkwitz-Riley 4次（2次のバターワースを2段・Q 0.7071）。低い側と高い側を足すと大きさは平ら（位相だけ回る）。
- オフのときは `bypass` 1・`wet` 0。切り替えは `setTargetAtTime`（0.02秒）でつなぎ、プツッと鳴らさない。
- コンプレッサー: `threshold`（しきい値）・`ratio`（強さ）・`knee` 6 dB・`attack` 0.003秒・`release` 0.12秒（固定）。
- メーターは `mix` から測る（聞いている音）。
- 抑えた量は `DynamicsCompressorNode.reduction`（dB・0 以下）を `SYNC_EMBED_LEVEL` に `compOn` / `compDb` として載せる（パネルが開いている間だけ届く）。

### 3-2. メッセージ（マイナー）

| 向き | 名前 | 中身 |
| :--- | :--- | :--- |
| A → 枠 | `SYNC_EMBED_COMP`（新） | `on, freq, threshold, ratio`。1秒ごとの `meterTick` で全 YouTube 枠へ送る＋設定を変えたらすぐ送る。`on:true` なら付け替えを許す |
| 枠 → A | `SYNC_EMBED_LEVEL`（既存） | `compOn`（今効いているか）・`compDb`（抑えた量） を足す |

### 3-3. A側（v2.18.0）

- `COMP_DEFAULTS = { on:false, freq:4000, threshold:-30, ratio:8 }`。`cardComp`（`sync_card_comp`）。
- 音量パネルのメーターの行に「🎚」ボタン（`volCompBtn_{cid}`・効いていれば強調）。押すと設定の行（`volComp_{cid}`）: ☑ 高音を抑える・帯域（1000〜12000 Hz・250 刻み）・しきい値（-60〜0 dB）・強さ（2〜20）・抑えた量。
- 付け替えをやめた動画（BROKEN）では「この動画では使えません」。
- 逃げ道 `COMP_FEATURE = false`。
- 版数: `APP_VERSION` 2.18.0・`ADDON_REQUIRED_VERSION` 2.16.0・`APP_HISTORY` 55件・`debug_suite.js` v1.28.0（`D-N3` 55）。

## 6. headless の確認（Chromium）

| 項目 | 結果 |
| :--- | :--- |
| 本物の音（440Hz＋8kHz の破裂）を枠の中の実コードに通す（`w18` 検証台） | オフ -13.3 dB → 強め（2kHz・-50 dB・20）-29.0 dB・抑えた量 37 dB・オフに戻すと -13.3 dB・コンプレッサーを入れていない枠は `compOn:false`・動画は止まらない |
| 🔴 実装中に見つけて直した2つ（オフラインの音の計算で確かめた） | ① **Web Audio の lowpass / highpass の Q は dB**。線形の 0.7071 を入れると境で山ができ、低い側＋高い側を足すと +3.3 dB 大きくなった → -3.01 dB（バターワース）。② **コンプレッサーは音を約 6ms（264 サンプル）遅らせる**ので、低い側とずれて境のあたりで打ち消し合った → 付け替えのときにその環境で遅れを測り（`compLatency`）、低い側を同じだけ遅らせる。直したあと、抑えていないときは 1k〜8kHz のどれでもオフと同じ -7.3 dB |
| 🔴 自動で持ち上げる分の打ち消し | Web Audio のコンプレッサーは抑えた分を自動で持ち上げる（makeup）。そのままでは境を上げると**オフより大きくなった**（-13.3 → -9.1 dB）→ `knee` 0 にして仕様の式（-0.6 × T × (1 - 1/R) dB）の分だけ後ろで下げる。直したあと、境 12kHz（8kHz の破裂は低い側）で -14.0 dB（オフ -13.3 dB とほぼ同じ） |
| メーターのスイッチを切った状態でコンプレッサーを入れる | 入れた枠だけ付け替わって効いた・入れていない枠は付け替わらない |
| `D-A8` | 21/21（PC 3/3）。変異（4通り: スイッチを切ると付け替えない／BROKEN でも on を送る／すぐ送らない／丸めない）→ いずれも不合格。旧版（v2.17.0）は「ある」が不合格 |
| `D-W10`（本物の枠の中のコード・検証台） | 5/5・効くまで 0.1秒・抑えた量 37.3 dB・遅れ 6ms・元に戻した。旧アドオン（2.15.0 の枠の中のコード）では「効いた」が不合格 |
| `D-A4` / `D-W3`（音量メーター） | 合格のまま（メーターは mix ＝ 聞いている音から測るように変えた） |
| 回帰 `▶ すべて実行` | 23本合格（1回目は検証台のブラウザが判定の前に落ちた・再実行で合格） |
| 用紙 `tests/test_v2_18_0.html` | R2 を貼って3つの照合が合格・開き直したあとの入力が届く |
