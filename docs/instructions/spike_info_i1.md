## 1. 目的

利用者の要望（2026-11-03）: 動画の**概要欄**と**コメント欄**（チャット欄ではない）を、チャット欄と同じ場所に排他で出したい。リンクは純正と同じ動き（外部リンクは別タブ）。

### 1-1. 🔴 利用者と決めたこと（2026-11-03）

| 項目 | 決めたこと |
| :--- | :--- |
| 切り替え | チャット欄の場所の上に「💬 チャット｜📝 概要欄｜🗨 コメント」のタブ。ヘッダーの 💬 は今どおり欄の開閉 |
| 時刻リンク（12:34 など） | **押した枠だけ**その時刻へシーク（純正と同じ） |
| 外部リンク | 別タブ |
| YouTube の中へのリンク（別の動画・チャンネル・ハッシュタグ） | 別タブで開く。🔴 **別の動画のリンクの横に ➕（アドオンの送信ボタンと同じく空き枠へ読み込む）を出す**（利用者の追加の要望） |
| コメント欄 | 純正に近く: 人気順／新しい順・返信を開く・下までスクロールで続き・高評価数と投稿者 |

### 1-2. 確かめること

- 概要欄: InnerTube `next` の `attributedDescription`（本文＋`commandRuns` のリンク）が取れるか・リンクの種類（時刻・外部・別の動画・チャンネル・ハッシュタグ）・位置が本文に収まるか・見出しの材料（視聴回数・日付）・予備の `player` の `shortDescription`・ログインなしでも読めるか。
- コメント: `next` の中のコメント欄の入り口（continuation）・1ページ目の形（`commentThreadRenderer` / `commentViewModel` / `commentEntityPayload`）・本文・投稿者・高評価数・返信数・コメントの中のリンク（時刻）・並べ替え（人気順／新しい順の token）・2ページ目・返信・ログインなし。
- 🔴 書き込まない（読むだけ）。出力に本文・投稿者名・リンク先を載せない（件数・種類・形だけ）。

## 2. 着手前に確かめたこと

| # | 確認 | 結果 |
| :-: | :--- | :--- |
| 1 | 取得の道筋 | チャット・投稿・視聴履歴と同じく、取得タブ（MAIN world・youtube.com の Cookie）から InnerTube を叩ける（v2.16.0〜v2.19.0） |
| 2 | チャット欄の開閉 | `chatVisible[cardId]`・`toggleChatVisibility`・`applyChatLayoutForCard`。流しはチャットのデータで動く（欄の表示とは別）→ 概要欄・コメントを出している間も流しは止めない方針 |
| 3 | 空き枠へ読み込む口 | アドオンの「➕送信」の受け口（空き枠へ流し込む処理）が A側にある → 概要欄の ➕ はこれを A側から直接呼ぶ |
