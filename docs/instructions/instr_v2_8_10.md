発行: 2026-10-02（Claude Code。管理と開発を同じセッションで行う）
基点: `index.html` v2.8.9 / アドオン 2.8.7 / `debug_suite.js` v1.11.0

## 1. やること

ローカル動画の枠の操作バーに **拡大** を置く。**「標準 / 枠いっぱい」と「🔍 100〜300%」**。表示値（`100%`）をダブルクリックで標準へ戻す。
🔴 **ローカル動画だけ**（利用者判断 2026-10-02）。🔴 **操作バーは切らない。**

## 2. 着手前に実コードで確かめたこと

| # | 確認 | 結果 |
| :-: | :--- | :--- |
| 1 | `<video>` の置き場所 | `.player-container`（`playerContainer_*`）の中に `position:absolute; 100%×100%`。既定の `object-fit` は `contain`（黒帯が出る） |
| 2 | 操作バー（`localOverlay_*`）の置き場所 | 🔴 **`.player-container` の外**（枠の直下）。→ **`<video>` だけを `transform: scale()` で拡大し、`.player-container` に `overflow:hidden` を付ければ操作バーは切れない** |
| 3 | 利用者の症状 | 「ウルトラワイドの動画で上下に黒帯が出て本体が小さくなる」。黒帯が**ファイルに焼き込まれている**場合は `object-fit: cover` では消えない → **倍率の拡大も要る**。枠の縦横比と違うだけなら「枠いっぱい（cover）」で足りる。両方を置く |
| 4 | ヘッダーにボタンを足せるか | ❌ 9枠で右端の余裕が 10px しかない（v2.8.8 `D-Y13`）。**操作バーに置く**（ローカル動画のときだけ出る） |
| 5 | 保存 | ローカル動画は再読み込みで消える（ファイルを持てない）ので**保存しない**。ファイルを替えたら標準へ戻す |
| 6 | 操作バーの HTML | 2か所（新規の枠・セッション復元）で同じものを組み立てている。両方に足す |
