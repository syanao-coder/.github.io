## 3. 設計

### 3-1. Google との接続

- ログイン: Google Identity Services の**トークン方式**（`google.accounts.oauth2.initTokenClient`）。スコープは **`https://www.googleapis.com/auth/drive.appdata`** だけ（このアプリ専用の隠しフォルダ。利用者のほかのファイルは見えない・触れない）。
- アクセストークンは**メモリにだけ**持つ（約1時間で切れる。`localStorage` に書かない）。切れたら、クリックの中（📂・保存・🔄）で取り直す。Google 側でログイン済みなら窓が一瞬開いて閉じる。
- 「同期を使う」状態（`sync_gdrive_on`）とクライアント ID（`sync_gdrive_client`）だけを `localStorage` に置く。
- ファイル: 隠しフォルダの `mylist.json` 1つ。
  - 探す `GET drive/v3/files?spaces=appDataFolder&q=name='mylist.json'`
  - 読む `GET drive/v3/files/{id}?alt=media`
  - 作る `POST upload/drive/v3/files?uploadType=multipart`（`parents:['appDataFolder']`）
  - 書く `PATCH upload/drive/v3/files/{id}?uploadType=media`
- 中身: `{ format:'sync-mylist', version:1, updatedAt, items:[マイリスト…], tombstones:{ id: 消した時刻 } }`

### 3-2. 両方の環境の変更を混ぜる（`mergeMylist`）

- ⭐ の各件に **`id`**（作った環境と時刻から一意）と **`updatedAt`** を持たせる。今ある ⭐（id なし）は最初の同期で id を付ける。
- 消した件は「墓標」（`sync_session_tombstones` に `id: 消した時刻`）を残す。墓標が無いと、もう一方の環境から復活してしまう。
- 混ぜ方（件ごと）: 手元・ドライブの件のうち `updatedAt` が新しい方を採る。どちらかの墓標の時刻がそれ以上なら消えたままにする。
- 墓標は180日で捨てる。⭐ は100件まで（新しい順）・🕒 は従来どおり10件。🕒 は同期しない。
- 同期の手順: 読む → 混ぜる → 手元へ反映 → ドライブと違えば書く。同期中に次の同期が来たら、終わってからもう1回だけ回す。
- ⚠️ A・B がほぼ同時に書くと、あとの方が勝つ（件ごとには混ざらない瞬間がある）。個人の2環境なので許容し、次の同期で直る。

### 3-3. 画面（📂 マイリストの中）

- 「自動保存（一括再生時・ページを閉じる前）」のスイッチ（`sync_autosave_on`・**既定オフ**）。
- 「☁ Google ドライブ同期」: クライアント ID の欄・「☁ Google でログイン」・「🔄 同期」・「ログアウト」・状態の行（未設定 / 同期中… / ☁ 同期済み 12:34（n件）/ ⚠ 理由）。
- 🔴 逃げ道: `GDRIVE_FEATURE = false` で欄ごと出さない。同期を使わなければ従来どおり（手元だけ）。

## 6. 🔴 利用者の準備（一度だけ・約10分）

1. `https://console.cloud.google.com/` を開き、Google アカウントでログインする
2. 上の「プロジェクトを選択」→「新しいプロジェクト」→ 名前（例: `sync-viewer`）→「作成」
3. 左のメニュー「API とサービス」→「ライブラリ」→ `Google Drive API` を検索 →「有効にする」
4. 「API とサービス」→「OAuth 同意画面」（「Google Auth Platform」と出ることがある）→「開始」→ アプリ名（例: 同時視聴ツール）・サポートメール（自分）→ 対象「外部」→ 連絡先（自分）→「作成」
5. 同じ画面の「対象」（または「テストユーザー」）→「ユーザーを追加」→ 自分の Gmail アドレス →「保存」（公開ステータスは「テスト」のままでよい）
6. 「クライアント」（または「認証情報」→「認証情報を作成」→「OAuth クライアント ID」）→ 種類「ウェブ アプリケーション」→「承認済みの JavaScript 生成元」に `https://syanao-coder.github.io` →「作成」
7. 表示された「クライアント ID」（`…apps.googleusercontent.com` で終わる文字列）をコピーし、ツールの 📂 マイリストの「☁ Google ドライブ同期」の欄に貼る（環境 A・B の両方で同じものを貼る）
8. 「☁ Google でログイン」→ Google の窓で自分のアカウントを選ぶ →「このアプリは Google で確認されていません」が出たら「続行」（自分で作ったアプリのため）→ 隠しフォルダへの許可を「続行」

⚠️ クライアント ID は秘密ではない（ページから見える種類の値）。秘密の値（「クライアント シークレット」）は使わないので、表示されても貼らない。
