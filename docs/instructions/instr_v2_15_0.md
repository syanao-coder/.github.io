## 3. 設計

- 保存の欄: `#sessionNameInput` の横に `<select id="sessionNameQuote">`「📋 タイトルを引用」。📂 を開いたとき・プルダウンを触ったときに、**今の枠の動画タイトル**（`getNewSessionState` の `players` のうち YT・ローカル）で選択肢を作り直す。選ぶと欄の文字を**置き換え**、欄にカーソルを移す（そのまま直せる）。同じタイトルは1つにまとめる。
- 一覧の各行に ✏（名前を編集）。押すとその行の下に編集の欄（名前・📋 引用（**その件の動画タイトル**）・保存・やめる）。Enter で保存・Esc でやめる。
  - 保存: 空なら保存しない（元のまま・状態に注意）。⭐ は `updatedAt` を今にして同期（`gdriveSync('rename', true)`）。🕒 は手元だけ。
  - 🔴 一覧が作り直されても編集の欄を保つ: 編集中の件を **id（無ければ timestamp）** で覚え、書きかけの文字も覚えて描き直す。保存も添字ではなく id で探す（同期で並びが変わっても別の件を書き換えない）。
- 名前の表示を `escapeHtmlAttr` へ（2節 #4）。
- 版数: `APP_VERSION` 2.15.0・`APP_HISTORY` 51件・`debug_suite.js` v1.25.0（`D-N3` 51）。
