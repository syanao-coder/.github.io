## 1. やること

`get-protocol-spec` 11節の保留（2026-10-24）: v2.12.3 の FREE「配信の終わり間近に流しが固まった → 同時表示数を上げたら解決」。既定 `maxOnscreen` を **40 → 60** へ。

- 値の根拠: 40 は「ラボの実測最大27の1.5倍」（アーカイブ基準・`get-danmaku-spec` 1-1節）。ライブは約10秒ごとの塊で届くので、同じ1.5倍の考えで 60。上限を大きくするほど 9枠で重くなる（同時の DOM 要素が最大 9×60）ので、100 にはしない。利用者が変えた値（`sync_flow_max_onscreen`）はそのまま。
- 変える箇所: `FLOW.maxOnscreen`・`FLOW_DEFAULTS.maxOnscreen`・スライダーの初期値（`value="60"`・「60件」）・`HELP_TEXTS.flowMaxOnscreen`（「既定は60件です。ライブで流れが詰まるときは上げ、重いときは下げてください」）。
- 版数: `APP_VERSION` 2.15.1・`APP_HISTORY` 52件・`debug_suite.js` v1.25.1（`D-N3` 52・`D-M7` の既定 60・`VERSION_FOCUS` = `D-V1` → `D-V2` → `D-M7` → `D-H1`）。
