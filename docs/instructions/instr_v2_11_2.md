# v2.11.2 指示書 ─ マイリストに各動画の再生位置を表示・音量ミキサーにチャンネル名

発行: 2026-10-21（Claude Code）

読む仕様書: `get-dev-workflow` / `get-debug-suite` / `get-ui-spec`（1節 トップメニュー・4節 更新履歴）/ `get-protocol-spec`（0-2節）
種別: **パッチ（A側だけ。メッセージは増やさない）。🔴 アドオンは変えない（`ADDON_REQUIRED_VERSION` は 2.11.1 のまま・zip も作らない）**

## 1. やること（利用者要望 2026-10-21）

1. マイリストの保存で、**各動画の再生位置**を記憶し、履歴の中に表示する（ボタンかマウスオーバーの別枠でよい）。手動保存のときだけでよい。内部タイマーの時刻は無くてよい。
2. 音量ミキサーの各行に、タイトルに加えて**チャンネル名**を出す（タイトルだけだと見分けにくい）。

## 2. 着手前に実コードで確かめたこと

| # | 確認 | 結果 |
| :-: | :--- | :--- |
| 1 | 🔴 **再生位置の保存（前提の食い違い）** | `getNewSessionState()` は**すでに枠ごとの `currentTime` を保存している**（YouTube は `getCurrentTime()`、ローカルは `video.currentTime`）。手動保存も自動保存も同じ関数。読み込み（`restorePlayerCardFromState`）は `playerVars.start` と `onReady` の `seekTo(p.currentTime)` で**その位置へ戻している**。→ **足りないのは表示だけ。** 過去の保存分にも位置が入っているので、表示を足せばそのまま見える |
| 2 | 履歴の表示 | `updateSessionListUI()` の2行目は `⏱ formatTime(session.globalTime)`（内部タイマー）と YT / Local の印だけ。タイトルも位置も出ていない |
| 3 | 履歴の行のクリック | 行の左側（名前と2行目）全体が `onclick="loadSessionByIndex(i)"`。中にボタンを置くなら `event.stopPropagation()` が要る（押すとセッションが読み込まれてしまう） |
| 4 | 音量ミキサー | `renderVolumeRows()` が開くたびに行を作り直す。1行は「枠N・種別・タイトル（`title_<cardId>` の文字）」 |
| 5 | チャンネル名の出どころ | A側にチャンネル名の取得は無い。YouTube の IFrame API の `getVideoData()` が `author`（チャンネル名）を返す。🔴 ただしコードの注記（v2.7.4）に「`getVideoData().title` は取れる回と取れない回がある」。→ **取れたものを動画ごとに覚えておき、取れないときは出さない** |
| 6 | 名前の埋め込み | 履歴の名前は `escapeJsString()`（`<` `>` を逃がさない）で HTML に入れている。新しく足す表示（タイトル・チャンネル名）は HTML として逃がす |

## 3. 設計

### 3-1. チャンネル名

- `getCardChannel(cardId)`: `ytPlayers[cardId].getVideoData()` の `author` を返す。取れたら `ytChannelByVideo[video_id]` に覚え、空のときは覚えた値を返す。どちらも無ければ空文字。
- 覚える機会を増やすため、`notePlayerState()` で再生（1）になったときにも1回呼ぶ。

### 3-2. 音量ミキサー

- 行の見出しを「枠N 種別 ／ タイトル ／ 📺 チャンネル名」の3段にする（チャンネル名が取れなければ3段目は出さない）。マウスを乗せたときの `title` にもタイトルとチャンネル名を入れる。

### 3-3. マイリスト

- 保存（`getNewSessionState`）: YouTube の枠に `channel` を足す（自動保存も同じ関数なので入る。手動に限る理由が無いので分けない）。
- 履歴の2行目: 内部タイマーの `⏱` をやめ、YT / Local の印の後ろに **`▸ 再生位置`** ボタンを置く。
  - 押すと、その下に枠ごとの行を開く: `枠N` ・印・タイトル（チャンネル名）・**再生位置**。もう一度押すと閉じる。
  - ボタンに `title` で同じ内容の文字（改行区切り）を持たせ、マウスを乗せるだけでも見える。
  - 🔴 ボタンは `event.stopPropagation()` で、セッションの読み込みを起こさない。
  - `channel` が無い（過去の保存）ときはタイトルだけ。空の枠は「（空）」。
- 読み込み（位置の復元）は変えない。

### 3-4. 版数

`APP_VERSION` 2.11.2・`ADDON_REQUIRED_VERSION` 2.11.1（据え置き）・`APP_HISTORY` 41件・`debug_suite.js` v1.19.0（`EXPECT_APP_VERSION` 2.11.2・`EXPECT_ADDON_REQUIRED` 2.11.1・`D-N3` 41）。
