# スパイク H1 記録 ─ YouTube の視聴履歴を読めるか

測定: 2026-10-30（利用者・Floorp・UA `Firefox/159.0`・YouTube の watch ページのコンソール）
指示書: `docs/instructions/spike_hist_h1.md` / 用紙: `tests/test_spike_hist_h1.html`（エンジン 3.0.1）/ 計測コード `hist-h1-1.0.0`
🔴 履歴のタイトル・ID・チャンネル名は記録しない（利用者が入れた2本の ID もここには書かない）

## 1. 結論

- 🔴 **作れる。** InnerTube `POST /youtubei/v1/browse`（`browseId: 'FEhistory'`）が、取得エンジンと同じ認証（`SAPISIDHASH`）で HTTP 200 を返した。`D-Q1` 合格 4/4・`D-Q2` 合格。
- 1ページ **199件**。動画 ID とタイトルは全件、サムネ・チャンネル・長さ・再生位置の印は 190/199（ショートの9件には無い）。日付の区切り（今日・昨日・曜日）7つ。続き（2ページ目）も 199件読めた。予備の `/feed/history` の HTML も同じ 199件・先頭5件が同じ。
- 🔴 **このツールの枠（埋め込み）で見た動画は、YouTube の履歴に載らない**（`D-Q2`: YouTube のサイトで見た動画は1番目・枠で見た動画は 398件の中に無い。R2 の目視でも同じ。「再生履歴を一時停止」はしていない）。→ YouTube の履歴は「YouTube のサイト（や他の端末）で見た動画」。枠の「🕒 最近使った動画」とは中身が別物なので、**共存させる方針（2026-10-26 合意）が正しかった**。
