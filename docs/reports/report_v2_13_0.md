## 3. 測れなかった値

- 🔴 **R6 で止まった原因。** A側からは「心拍が来なくなった」ことしか分からない（取得タブが止まった・閉じられた・アドオンの中継が切れた・取得のエンジンが例外で落ちた、を区別できない）。`chatError` の文言（見張りの発火なら「取得が 45 秒間停止しました…」、B側の失敗ならその理由）も `D-L9` が記録していない。
- v2.13.0 の変更（視聴者数の要求）との関係。取得のループで変えたのは「`await` しない要求を投げる」だけで、検証台では要求が返らなくてもチャットは止まらなかった。ただし実機で否定はできていない。
- 予備の watch 経路（2分ごとの確認での視聴者数）。
