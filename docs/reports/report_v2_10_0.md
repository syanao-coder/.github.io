## 2. 実測

| 項目 | 値 |
| :--- | :--- |
| D-K2 `zuuZyNH0F1Y` すべて | **356件**（既知値と一致）・`view=all`・reqs 11・elapsed 2,221ms |
| D-K2 同 上位 | **350件**（−6件）・`view=top`・reqs 10・elapsed 2,012ms |
| 切替後のすべての側 | 参照が無くなり破棄された（`releaseUnusedChatData`） |

- 🔴 **D-A2 判定不能の原因は基盤側**: 利用者の画面が1枠だけで、PC「枠が2つ以上ある」が不成立。v1.17.1 で「足りなければ1枠足して測り、後で戻す」に直した（headless で1枠・2枠の両方から合格・枠数が戻ることを確認）。本体の不具合ではない。
- 🔴 **管理側の誤り**: v2.8.13・v2.9.0 で Python の `open()` で書き換え、アドオン2本の改行を CRLF → LF にしていた。今回4本で同じことが起きて差分が全行になり発覚。本版で CRLF に戻した（鉄則 #49）。
