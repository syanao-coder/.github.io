## 2. 実機で確かめた前提（指示書 6節の「未確認の前提」）

| # | 前提 | 結果 |
| :-: | :--- | :--- |
| 1 | Floorp の content script からの `postMessage` で `event.source` が iframe の `contentWindow` と一致する | ⚪ D-W1: 2枠とも `how=source`・返事まで約1.0秒（点呼の再送間隔ぶん） |
| 2 | 本物の embed の「その他の動画」（一時停止時）・終了画面の動画が `a[href]` の `click` で開く | ⚪ 目視 R3・R4 で枠に入った（別タブなし） |
| 3 | 中クリック・タイトルは止めない | ⚪ R5 / R5b とも別タブ |

- D-W2 の 3秒後の `playerState` は **5（cued）**＝読み込んだだけで再生していない。

## 3. 測れなかった値

| # | 値 | 理由 |
| :-: | :--- | :--- |
| 1 | `videoId` 照合（`source` が一致しないときの予備経路）の実機での発火 | 実機では `source` で全件決まったため通らない。検証台でのみ確認 |
| 2 | 再生リスト付きの枠で関連動画を押したときの `list` の扱い | 未測定（候補リンクに `list` があれば付けて読み込む作り） |
| 3 | 終了後に YouTube が自動で次の動画へ進む（autonav）場合 | embed では通常起きない。未測定 |
